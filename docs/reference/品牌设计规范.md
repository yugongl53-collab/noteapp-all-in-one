# 品牌与视觉设计规范

本文档为「一站笔记」（NoteApp All-in-One）的官方品牌视觉设计规范，明确了应用命名、标语、色彩体系、5大核心功能模块视觉符号、资产文件组织以及 README / 社区展示规范。

---

## 1. 品牌定位与标识

### 1.1 命名与标语
- **中文名称**：一站笔记
- **英文名称**：NoteApp All-in-One
- **官方 Slogan**：一站式个人效率工具 · 灵感 · 日程 · 专注 · 统计
- **设计风格**：Android Material Design 3 现代质感，融合毛玻璃微质感（Glassmorphism）与清新、克制的高效工具美学。

### 1.2 品牌 Logo (`docs/assets/logo.svg`)
- **构形含义**：以字母「N」为主干，左侧起笔为干练的几何直线，斜笔向右上方跃升，右侧融入笔尖与灵感火花（Inspiration Spark），象征灵感随记、日程规划与时间积累。
- **背景形态**：Material 3 连续平滑圆角（Squircle，22% 圆角半径）。

| 模块名称 | 视觉符号 | 模块英文 | 主题强调色 (Hex) | 浅色背景色 (Hex) | 深色背景色 (Hex) | 核心职责说明 |
| :--- | :---: | :--- | :--- | :--- | :--- | :--- |
| **灵感记录** | 📝 | Quick Note | `#6366F1` (Indigo) | `#EEF2FF` | `#1E1B4B` | 闪念即开即记、便签标签整理、回收站防误删 |
| **学期日程** | 📅 | Semester Schedule | `#0284C7` (Sky Blue) | `#F0F9FF` | `#082F49` | 学期周课表视图、单次/循环日程流、准点闹钟提醒 |
| **番茄专注** | 🍅 | Pomodoro Focus | `#E11D48` (Rose) | `#FFF1F2` | `#4C0519` | 沉浸番茄钟倒计时、阶段切换确认、全局底部常驻条 |
| **随机决策** | 🎲 | Random Decision | `#D97706` (Amber) | `#FFFBEB` | `#451A03` | 待办行动选择池、等概率/加权抽取、一键带入番茄钟 |
| **时间统计** | 📊 | Time Analytics | `#059669` (Emerald) | `#ECFDF5` | `#022C22` | 五类实际事件性质、日周精准时长排行榜、JSON 备份恢复 |

## 4. README 与社区排版规范

### 4.1 深浅色自适应 Banner 嵌入方式
在 `README.md` 顶部，使用标准 HTML `<picture>` 标签实现根据访问者系统或 GitHub 主题（Light / Dark）自动切换对应的矢量横幅：

```html
<p align="center">
  <picture>
    <source media="(prefers-color-scheme: dark)" srcset="docs/assets/banner-dark.svg">
    <source media="(prefers-color-scheme: light)" srcset="docs/assets/banner-light.svg">
    <img alt="一站笔记 NoteApp All-in-One Banner" src="docs/assets/banner-light.svg" width="100%">
  </picture>
</p>
```

## 5. 衍生设计与版本演进准则
1. **矢量优先**：新增页面配图或图标设计优先归档 SVG 格式，确保在不同 DPI 屏幕下渲染清晰。
2. **主题一致**：深色模式使用高明度强调色与深底黑（`#0B0F19`），浅色模式使用深沉文本与明亮白底（`#FFFFFF` / `#F8FAFC`）。
3. **功能同步**：若后续模块或核心功能发生增删，需在同一任务中同步更新 Banner、设计规范文档与 README 展示。
