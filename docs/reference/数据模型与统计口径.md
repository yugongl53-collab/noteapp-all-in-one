# 数据模型与统计口径草案

## 1. 文档目的

本文档定义 MVP 需要表达的数据实体、字段约束和时间统计口径，减少后续实现中对同一概念的不同解释。它是设计草案，不代表数据库结构已经实现；具体类型应按最终技术栈映射。

## 2. 固定分类

内部应使用稳定标识，界面显示中文名称，避免未来文案调整破坏历史数据。

| 稳定标识 | 显示名称 | 可由用户选择 |
| --- | --- | --- |
| `work_study` | 工作学习 | 是 |
| `high_quality_entertainment` | 高质量娱乐 | 是 |
| `low_quality_entertainment` | 低质量娱乐 | 是 |
| `social` | 社交 | 是 |
| `other` | 其他 | 否，仅统计时派生 |

日程任务、事件池项目和时间记录只允许保存前四个标识。`other` 不得作为这些实体的持久化分类值。

## 3. 核心实体

### 3.1 灵感 `Idea`

| 字段 | 用途 | 必填 | 约束 |
| --- | --- | --- | --- |
| `id` | 本地唯一标识 | 是 | 创建后不可变。 |
| `content` | 灵感正文 | 是 | 去除首尾空白后非空。 |
| `tags` | 简单标签集合 | 否 | 同一灵感内去重。 |
| `createdAt` | 创建时间 | 是 | 绝对时间戳。 |
| `updatedAt` | 最后更新时间 | 是 | 不早于 `createdAt`。 |

### 3.2 日程任务 `ScheduleTask`

| 字段 | 用途 | 必填 | 约束 |
| --- | --- | --- | --- |
| `id` | 本地唯一标识 | 是 | 创建后不可变。 |
| `title` | 任务标题 | 是 | 去除首尾空白后非空。 |
| `category` | 固定分类 | 是 | 只能是四个可选分类之一。 |
| `type` | 任务类型 | 是 | `weekly` 或 `one_off`。 |
| `weekdays` | 循环星期集合 | 条件必填 | `weekly` 至少选择一天，`one_off` 不使用。 |
| `effectiveFrom` | 循环生效日期 | 条件必填 | `weekly` 必填，默认创建当天；`one_off` 不使用。 |
| `date` | 具体日期 | 条件必填 | `one_off` 必填，`weekly` 不使用。 |
| `startTime` | 当地开始时刻 | 是 | 必须早于 `endTime`。 |
| `endTime` | 当地结束时刻 | 是 | MVP 不允许跨午夜。 |
| `createdAt` | 创建时间 | 是 | 绝对时间戳。 |
| `updatedAt` | 最后更新时间 | 是 | 绝对时间戳。 |

所有生效的日程都应该被渲染到时间表。
周视图按查看周的当地日期展开循环规则，不需要为每周预先复制一批任务记录。

### 3.3 事件池项目 `EventPoolItem`

| 字段 | 用途 | 必填 | 约束 |
| --- | --- | --- | --- |
| `id` | 本地唯一标识 | 是 | 创建后不可变。 |
| `title` | 候选行动名称 | 是 | 去除首尾空白后非空。 |
| `category` | 固定分类 | 是 | 只能是四个可选分类之一。 |
| `isEnabled` | 是否参与抽取 | 是 | 默认启用。 |
| `createdAt` | 创建时间 | 是 | 绝对时间戳。 |
| `updatedAt` | 最后更新时间 | 是 | 绝对时间戳。 |

### 3.4 时间记录 `TimeRecord`

| 字段 | 用途 | 必填 | 约束 |
| --- | --- | --- | --- |
| `id` | 本地唯一标识 | 是 | 创建后不可变。 |
| `title` | 实际活动名称 | 是 | 去除首尾空白后非空。 |
| `category` | 固定分类 | 是 | 只能是四个可选分类之一。 |
| `startAt` | 实际开始时间 | 是 | 带时区语义的绝对时间戳。 |
| `endAt` | 实际结束时间 | 是 | 必须晚于 `startAt`。 |
| `source` | 记录来源 | 是 | 默认为 `manual`（手动打卡/补录）。 |
| `relatedTaskId` | 关联日程任务 | 否 | 任务删除后不应导致记录丢失。 |
| `relatedPoolItemId` | 关联事件池项目 | 否 | 项目删除后不应导致记录丢失。 |
| `createdAt` | 创建时间 | 是 | 绝对时间戳。 |
| `updatedAt` | 最后更新时间 | 是 | 绝对时间戳。 |

关联字段只用于追溯来源，统计以记录自身保存的标题、分类和时间为准，避免原任务修改后篡改历史统计。

### 3.5 番茄钟会话 `PomodoroSession`

| 字段 | 用途 | 必填 | 约束 |
| --- | --- | --- | --- |
| `id` | 会话唯一标识 | 是 | 创建后不可变。 |
| `title` | 本轮事项 | 否 | 用于界面提示。 |
| `plannedFocusMinutes` | 计划专注分钟数 | 是 | 必须为正数，范围待技术确认。 |
| `startedAt` | 实际启动时间 | 是 | 绝对时间戳。 |
| `pausedDuration` | 累计暂停时长 | 是 | 不得为负数。 |
| `state` | 会话状态 | 是 | 具体状态集合随恢复策略确定。 |

番茄钟会话仅表示前端/本地计时器的当前运行状态，纯粹作为专注工具，不生成 `TimeRecord`，不参与任何时间统计。

## 4. 周时间视图展开规则

1. 以设备当前时区确定目标自然周，周一 00:00 为开始。
2. `weekly` 任务根据 `weekdays` 匹配目标周中的当地日期，并且只显示在 `effectiveFrom` 当天及之后。
3. `one_off` 任务根据 `date` 是否落在目标周内判断是否展示。
4. 只渲染启用任务；任务时间不等于实际执行时间。
5. 重叠任务都保留，界面负责并排或错开展示。

## 5. 抽奖规则

设启用事件池集合为 `E`：

- 当 `E` 为空时，返回“没有可抽取项目”的业务状态。
- 当 `E` 非空时，每项被抽中的概率均为 `1 / |E|`。
- 单次结果不修改下一次抽取的概率。
- 停用或已删除项目不进入候选集合。

测试随机功能时不能要求短样本严格平均；应验证结果始终来自有效集合，并通过足够样本检查不存在明显固定偏向。

## 6. 时间记录有效性

- `endAt` 必须晚于 `startAt`。
- 一条记录可以跨日期，但统计时必须按当地自然日边界切分。
- 任意两条有效时间记录不能覆盖同一个实际时间片段；相邻记录首尾相接不算重叠。
- 时间记录由用户手动打卡录入，必须提供真实有效的起止时间。
- 修改记录时，应排除当前记录自身后再检查重叠。

## 7. 日统计口径

对目标当地自然日 `D`：

1. 将与 `D` 相交的每条时间记录裁剪到当天边界。
2. 按分类累加裁剪后的分钟数，得到四类时长 `C1...C4`。
3. 已记录总时长 `R = C1 + C2 + C3 + C4`。
4. 分类占已记录时间比例：当 `R > 0` 时为 `Ci / R`；当 `R = 0` 时四类均显示 0%。
5. 其他时长 `O = max(0, 当天总分钟数 - R)`。

默认产品表达中的“当天总分钟数”为 1440 分钟。若产品需要正确覆盖夏令时切换日，应改用该时区自然日的实际分钟数；这是编码前待确认决策。

“其他”表达未被有效记录覆盖的时间，包含睡眠、通勤、家务和未打卡时间。它不代表低效率，也不参与四类“已记录时间占比”的分母。

### 示例

某天记录工作学习 6 小时、高质量娱乐 1 小时、低质量娱乐 2 小时、社交 1 小时：

- 已记录总时长为 10 小时。
- 四类占比分别为 60%、10%、20%、10%。
- 其他为 14 小时。

## 8. 周统计口径

- 周一至周日分别按日统计规则切分和汇总。
- 某分类周总时长等于七天该分类时长之和。
- 四类周占比的分母为全周四类已记录总时长，不包含“其他”。
- 周“其他”可展示为七天其他时长之和，但需明确它是未记录时间。
- 切换周次只改变查询范围，不修改原始时间记录。

## 9. 时间与时区

- `createdAt`、`updatedAt`、`startAt` 和 `endAt` 应保存为绝对时间点；展示时转换到设备当前时区。
- 周期任务的星期和时刻属于当地日历规则，不应简单当作固定 UTC 时刻保存。
- 用户跨时区后，历史记录按“当前时区”还是“创建时区”归日会影响统计，必须在编码前选择并形成测试。MVP 若只支持设备当前时区，也要明确提示其限制。

## 10. 删除与历史一致性

- 删除日程任务或事件池项目，不应级联删除已经生成的时间记录。
- 时间记录保存自己的标题和分类快照，保证历史统计可重算。
- 删除时间记录会改变统计，应在确认后立即重算。
- 回收站或软删除尚未确定，不在当前模型中假定已支持。
