# 一站笔记页面与交互说明

## 1. 文档目的

本文档把产品需求转换为页面结构和主要交互路径，供界面实现和验收使用。M2 至 M7 的业务闭环已经实现，已重构为四大主 Tab 导航架构；正式交付仍需完成 API 31 与实体手机验收并使用用户 keystore 签名。

MVP 使用简洁蓝色 Material 3 风格并跟随系统明暗主题，只适配手机竖屏。所有日程、时间记录和番茄钟时长输入精确到分钟。

## 2. 导航结构

底部固定四大主选项卡：

1. **日程**（整合课表、事件流与时间统计）
2. **灵感**（灵感记录、便签列表与回收站）
3. **工具箱**（番茄钟专注计时与事件抽奖决策池）
4. **设置**（主题切换、数据备份/恢复、系统权限管理）

普通事件配置、课程配置和学期配置作为二级界面从“日程”进入；灵感回收站和灵感全量编辑从“灵感”进入；番茄钟与事件池抽奖聚合在“工具箱”主页面；系统权限与数据备份恢复位于“设置”。番茄钟在后台运行时，在其他主页面持续显示紧凑状态条，点击可直达工具箱番茄钟计时页。

各主 Tab 切换支持 `saveState` 与 `restoreState`，返回栈遵循 Android 标准。

## 3. 日程页（含课表、事件流与时间统计）

日程页顶部先显示当前时期状态按钮，再提供“课表”、“事件流”和“时间统计”三个视图切换入口。状态按钮描述设备当天，切换视图或浏览其他周不会改变它；点击按钮直接打开学期设置。

- 当天位于学期内：显示标准学期名称和周次，例如 `2026-2027秋季学期 · 第3周`。
- 当天位于已配置学期之外：按相邻学期季节显示“寒假中”或“暑假中”。
- 尚未配置任何学期：显示“未设置学期”。

### 3.1 课表视图

#### 页面布局

- 周控件显示正在浏览的周日期范围、上一周、下一周和返回本周按钮。学期与周次信息统一由页面顶部常驻时期状态栏展示。
- 主体横向为周一至周日，纵向为一天的时间刻度。
- 屏幕不足以完整显示七列或单日事件超出垂直可视区域时，支持横向与纵向双向滚动；当天列使用轻量高亮。
- 普通事件块使用事件性质颜色，并显示名称和起止时间；课程块显示课程名称、地点和起止时间。

#### 操作规则

- 点击事件块：打开只读详情，并提供“删除”（需二次确认）与“前往编辑”。
- 新增按钮展开“添加普通事件”和“添加课程”两个明确入口，不用一个表单中的隐藏开关混合创建。
- 添加普通事件时，日期或星期可根据当前周预填；添加课程时，所属学期可根据当前周预填。
- 不支持在课表中拖拽、缩放或直接改时间。
- 重叠事件同时可见，不让后创建的事件遮住先创建的事件。

#### 空状态与错误状态

- 当前周无事件：保留完整时间网格并显示普通事件和课程两个新增引导。
- 周数据读取失败：显示重试，不把错误误呈现成“本周无事件”。

### 3.2 事件流视图

- 视图将本周普通事件和课程展开成具体实例，按开始日期时间从早到晚采用纵向卡片列表排列展示，可纵向滚动。
- 当天事件自动以上下午（以 12:00 为界）分块排布；上下午区块之间保留视觉留白/空白间距自然隔开，不显示“上午”、“下午”等显式文字标签。
- 当前时刻以事件结束时间为过滤边界：`endAt <= now` 的已结束事件不显示，正在进行和未来事件继续显示。
- 正在进行的事件显示“进行中”；在所有 `startAt > now` 的事件中，最早开始的一项使用特殊边框并标记“下一个事件”。
- 若多个事件同时成为下一项，它们都使用特殊边框，避免任意隐藏并列事件。
- 每周循环普通事件和课程只展开当前自然周的实例；单次普通事件也只显示落在本周且尚未结束的记录。
- 卡片显示日期、星期、起止时间、名称和事件性质；课程卡片必须额外显示地点。
- 点击事件卡片：打开只读详情，可选择删除（需二次确认）或前往编辑。
- 当前周没有未结束事件时，显示“本周没有接下来的事件”。

### 3.3 时间统计视图

该视图用于复盘已经发生的实际活动，不把课表计划自动当作时间记录。前置条件仅为已经手动录入时间记录；没有记录时显示空状态和“手动录入”入口。

1. 选择“日”或“周”，通过前后按钮切换日期或自然周，也可回到当前时段。
2. 在“按事件性质”和“按事件名称”之间切换排行榜；两者显示同一范围内的精确累计时长。
3. 点击“手动录入”新增实际活动，或在明细中编辑、永久删除记录；保存时继续执行无效范围与任意重叠校验。
4. 周统计额外展示周一至周日的每日记录与未记录时长；五类事件性质和同名汇总规则保持不变。

最小验证可录入同一天两条首尾相接记录，确认均能保存且榜单立即汇总；再尝试录入覆盖任一已有时间片段的记录，预期表单保留输入并提示重叠。切换到周统计后，记录应出现在正确自然日，删除后日、周排行榜和快捷名称立即重算。

## 5. 普通事件与课程配置

### 5.1 普通事件配置

#### 事件列表

- 按“每周循环”和“单次事件”分组。
- 每项显示名称、事件性质、适用日期或星期、时间和启用状态。
- 循环事件支持停用；停用后保留配置但不再渲染。

#### 编辑表单

共同字段：

- 事件名称（必填，可自由填写）
- 事件性质（必选）
- 开始时间（必填）
- 结束时间（必填）
- 提醒开关（默认开启）
- 提前分钟数（开启提醒时必填，默认 5 分钟）

类型字段：

- 单次：选择一个具体日期（表单默认选中单次）。
- 每周：选择一个或多个星期；生效日期默认当天，用户可以修改。

名称输入框下方显示由当前仍存在的同类普通事件生成的去重快捷选项，最近使用的名称优先。点击只填充名称，不覆盖其他字段，用户可以继续修改或输入全新名称。

提交时先验证必填项和时间范围，再检查与已有事件的重叠。重叠提示允许用户确认继续，非法时间范围必须修正后才能保存。

用户可以逐项关闭提醒或修改提前分钟数。保存时提醒时间已经过去、但事件尚未开始，则立即提醒一次；事件已经开始或结束时不补发。缺少通知或“闹钟和提醒”权限不阻止保存，但表单和列表都要显示“提醒未启用”并提供系统设置入口。

### 5.2 课程配置

- 课程列表按所属学期分组，每项显示课程名称、地点、星期、时间和上课周范围。
- 表单必填所属学期、课程名称、地点、至少一个星期、开始时间、结束时间、开始周和结束周。
- 课程固定显示“学习”，不提供其他事件性质选项。
- 开始周、结束周使用正整数输入；超出所属学期实际周数或开始周大于结束周时，在字段附近提示并阻止保存。
- 课程名称可自由填写；输入框提供当前仍存在课程名称的去重快捷选项。选择名称不自动带入地点、周次或时间，避免沿用错误配置。
- 课程默认开启提前 25 分钟提醒，用户可以逐项关闭或修改提前分钟数；权限失败和错过提醒时间的处理与普通事件一致。
- 尚未设置学期时，课程表单不可保存，并指引用户关闭表单后点击顶部时期状态按钮。

### 5.3 学期设置

- 只能通过日程顶部时期状态按钮进入，不与普通事件、课程管理按钮并列。
- 列表显示标准学期名称、开始日期和结束日期，支持新增、编辑和删除。
- 表单填写学年起始年份、秋季或春季、开始日期和结束日期；开始日期晚于结束日期或与现有学期重叠时阻止保存。
- 修改学期不能让已关联课程的周范围超过新学期实际周数；存在此类课程时先调整课程。

### 5.4 历史名称快捷选项通则

- 快捷选项只是一种输入辅助，不限制用户自由填写新名称。
- 普通事件、课程、事件池项目和时间记录分别从各自当前仍存在的数据生成候选，不跨类型混合。
- 候选去除首尾空白后按完整名称去重，最近更新的名称排在前面。
- 数据永久删除后不得为了建议功能保留隐藏副本；某名称不再有任何现存来源时，从对应快捷选项消失。

## 5. 灵感页

### 快速灵感记录

- 列表顶部常驻快速灵感输入卡片，包含正文与可选标签输入。
- 支持直接输入后点击“保存灵感”实时入库，无需离开当前页面。

### 灵感列表

- 顶部显示“灵感”标题和回收站入口。
- 卡片显示正文摘要、标签和最后更新时间。
- 默认按最后更新时间倒序排列。

### 全量编辑

- 右下角 FAB 新增入口与卡片点击均进入全量编辑界面。
- 正文为主要输入区域，标签为次要输入。
- 标签输入使用半角逗号、中文逗号或换行分隔；保存时去除空白标签，并按首次出现顺序合并重复标签。
- 离开未保存内容时需要提示，避免误丢失。
- 删除操作必须二次确认；确认后移入回收站，不立即永久删除。

### 回收站

- 回收站按删除时间倒序展示灵感，并显示距离自动永久删除的剩余时间。
- 灵感从删除时刻起保留 30×24 小时，期间可以恢复到灵感列表或手动永久删除。
- 到期灵感自动永久删除；恢复后清除删除时间，并按原有 `updatedAt` 参与列表排序。

### 空状态

用一句行动文案引导用户记录第一条想法，并在上方提供输入卡片与右下角新增按钮。

## 6. 工具箱（番茄钟与事件抽奖）

工具箱作为底栏 4 大主选项卡之一，聚合展示“番茄钟”与“事件池与抽奖”两大核心卡片。

### 6.1 番茄钟专注模块

#### 未开始状态
- 显示事项名称输入框（可选），并提供现存事件池名称快捷标签。
- 专注时长（1–180 分钟）与休息时长（1–60 分钟）设置，默认采用最近使用的配置。
- 点击“开始专注”开启倒计时，并在未授权通知权限时引导授权。

#### 运行与暂停状态
- 大号显示剩余倒计时时间与当前阶段（专注中 / 休息中）。
- 快捷操作按钮：暂停、继续、重置、提前结束。
- 支持点击右上角全屏图标展开完整全屏沉浸专注视图。
- 离开工具箱后在其他主页面底部保持显示紧凑浮动计时条（`PomodoroCompactBar`），点击可直达工具箱。
- 应用被系统终止、异常退出或设备重启后，依据持久化绝对截止时间恢复剩余时间；已结束阶段显示完成状态，不补发过期通知。

#### 阶段完成与反馈
- 倒计时结束时给出完成提示。
- 专注结束后显示“开始休息”，由用户确认后才启动休息；休息结束后不自动启动下一轮专注。
- 纯粹作为专注辅助工具，不产生任何时间记录或统计数据。

### 6.2 事件抽奖决策模块

#### 加权转盘
- 卡片顶部显示当前已启用候选事件数量与总数；彩色转盘只渲染启用项，并用扇区角度、名称和百分比表达各项权重占比。
- 点击中心“抽一下”或结果卡片“再抽一次”，系统先按权重确定结果，再用减速动画把中选扇区中心精确停到正上方指针。
- 没有启用项目时展示空池提示并引导添加项目。
- 只有一个启用项时展示完整单色圆并直接命中；抽中后展示名称、事件性质和权重，支持一键“带入番茄钟”填入番茄钟事项。

#### 事件池管理
- 点击“管理事件池”展开全量事件池管理界面。
- 列表展示各项名称、事件性质、权重、当前占比和启用开关，支持开关切换、编辑、删除与新增。
- 名称允许自由填写并提供历史快捷项；权重使用 `1–100` 计数器，表单实时显示启用后的总权重占比；名称为空、未选事件性质或权重越界时不得保存。

## 7. 设置页

### 外观主题

- 展示应用品牌与版本信息。
- 提供外观主题设置项，支持三种模式单选：
  - 📱 跟随系统（默认）：跟随系统深浅色外观，并在 Android 12+ 设备上自动适配壁纸动态取色。
  - ☀️ 浅色模式：强制使用浅色主题。
  - 🌙 深色模式：强制使用深色主题。
- 用户点击选择后即时生效，并持久化保存至本地 DataStore，应用重启后保持用户选择。

### 提醒权限

- 分别展示通知权限和“闹钟和提醒”特殊权限状态：番茄钟阶段提醒依赖通知权限，课程与普通事件同时依赖两项权限。
- 权限未授予时提供系统设置入口，不重复弹出误导性授权提示，也不把未调度提醒显示为已开启。
- 获得权限后重新调度所有未来且已开启的日程提醒；权限被撤销后保留提醒配置，但明确显示未生效。

### 数据备份与恢复

- **文案通俗化设计**：彻底消除面向普通用户的编程与技术术语（如 `formatVersion`、`JSON 序列化`、`UTF-8 明文`、`DAO 数据项`、`实体校验`、`事务替换` 等），全部采用自然通俗中文描述。
- **数据导出**：
  - 说明文案：“将您所有的笔记、日程、专注历史和统计记录打包保存为一个备份文件。该文件可以存放在手机或发送给其他设备，请妥善保管。”
  - 点击“导出数据备份”后弹出确认弹窗并提示文件包含个人数据，确认后调用系统文件选择器选择保存位置。
  - 导出成功提示“数据备份已成功导出”，失败提示“数据备份导出失败，请重试”。
- **数据恢复**：
  - 点击“从备份文件恢复数据”后调用系统文件选择器选择备份文件。
  - 校验文件合法性；若文件损坏或格式不符，提示“文件格式不符合要求或已损坏，未能读取数据”。
  - 校验通过后弹出确认弹窗，通俗展示所包含的各项数据数量（灵感笔记、日程事件、学期、课程、决策池项目、时间记录），并醒目提示“⚠️ 请注意：恢复数据将会覆盖并替换当前应用内的全部现有数据，此操作无法撤销。是否继续？”。
  - 确认后整体恢复数据并重建有效日程提醒。成功提示“数据已成功恢复并同步”，失败提示“数据恢复失败，原有数据未受影响”。

## 12. 全局反馈原则

- 保存成功：使用短暂且不打断操作的反馈。
- 校验失败：在对应字段附近说明如何修正。
- 系统错误：保留用户输入，提供重试，不只显示错误代码。
- 删除和放弃计时：使用明确确认，不把主要按钮设计成容易误触的危险操作；时间记录删除确认必须说明不可恢复。
- 空状态：解释为什么为空，并提供唯一清晰的下一步。
- 加载状态：已有内容尽量保持可见，避免整页闪烁。
- 提醒权限不足：允许保存业务数据，但必须显示提醒未生效的具体原因和设置入口。

## 13. 基础无障碍要求

- 事件性质和“下一个事件”不能只靠颜色区分，还要显示文字或图形标记。
- 触控区域应足够大，重要按钮不能贴近系统手势区域。
- 支持系统字体放大后完成核心操作。
- 排行榜应提供正确的读屏顺序，读出名次、名称和精确时长。
- 动画不影响功能判断，并尊重系统减少动态效果设置（若所选框架支持）。
