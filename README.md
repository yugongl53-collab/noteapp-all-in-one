# NoteApp All-in-One

NoteApp All-in-One 是一款处于产品规划阶段的 Android 个人效率应用，目标是把灵感记录、周时间安排、番茄钟、随机行动选择和时间统计集中在一个轻量工具中。

> 当前状态：仅完成项目文档，尚未编写应用代码，也没有可安装版本。项目名称为暂定名称。

## 核心能力

- 打开应用后快速记录想法，并用简单标签整理。
- 使用类似大学课表的周视图查看固定循环任务和单周临时任务。
- 提供纯粹的番茄钟专注计时工具，辅助专注执行。
- 从预先维护的事件池中随机抽取一件事。
- 将实际时间归入“工作学习、高质量娱乐、低质量娱乐、社交”四类，查看日、周统计。
- 自动计算未被四类记录覆盖的“其他”时间；“其他”不是用户可选分类。

## 目标用户

适合希望用一个本地、低门槛工具完成记录、安排和时间复盘的个人用户，尤其适合不想在多个笔记、日历、计时器应用之间切换的人。

## MVP 边界

首个版本按单用户、单设备、本地优先设计，不承诺账号体系、云同步、多人协作、桌面端或复杂提醒。具体技术栈、最低 Android 版本、数据备份方案和通知策略需要在编码前确认。
